Steps for local setup: 
1. Create .env file and set the PROJECT_PATH variable to your DW_BI repo location
e.g: 
PROJECT_PATH=D:\MyProjects\BDTS\modbd
2. In OracleDocker/mounts, create an empty oradata folder. It will be used by the Oracle container 
3. Continue the steps from here (the images are very useful too):
